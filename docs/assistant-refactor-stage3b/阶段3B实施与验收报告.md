## 依赖关系对比

旧链：旧总控制器 → 关键词/意图规则 → workflow / monitoring-query / alarm-orders / 前端模型适配；存在前端直接业务编排。

当前链：文字或语音转写 → InspectionAssistant → agent-assistant → agent-conversation → agent-client → 服务端大模型白名单工具循环。写入：服务端 prepare → 确认卡片按钮 → pendingToken + kind + requestId → 服务端权限/有效期/状态/幂等校验 → 既有业务 Service。

场景：服务端 clientAction → scene-action-executor → 现有 RoomScene → 结构化 scene-result。主页明确动作：home-scene-controls → 同一执行器；不经自然语言解释器或旧查询器。

本轮未修改 Agent 生产代码、后端核心 Service、数据来源策略、模型提供商、依赖、数据库结构或场景模型实现。IntegrationController、IntegrationService 和 scene.ts 哈希与记录一致；旧 /api/v1/assistant/chat 保留。
