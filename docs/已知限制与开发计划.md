# 已知限制与后续开发计划

## 当前限制

| 领域 | 当前行为与影响 |
| --- | --- |
| 演示数据 | 公开种子是合成数据，不含真实用户或设备；读数为初始化时快照，不是持续运行的采集器，过期后不能用来通过真实复检 |
| 来源字段 | 部分现有查询与迁移统一使用 REAL；判断真实采集需结合 source、simulated 与采集证据，不能只看 recordOrigin |
| 视频与物理设备 | 自带 MP4 仅作展示；实时视频、采集和控制依赖外部网关，三维动画或本地控制状态不代表物理设备动作 |
| 部署规模 | 参考方案为单实例部署；助手存在进程内会话锁，多实例并发与任务调度尚未完成分布式协调 |
| 初始化与迁移 | 管理员和公开演示数据已有独立工具；schema 仍混合 SQL 与启动时建表/升级，MySQL DDL 不能整体事务回滚，尚无统一迁移版本发布机制 |
| 鉴权与访问 | 当前主要是管理员和维保两类角色；未提供多租户隔离或完整细粒度权限，部分接口允许跨域通配来源 |
| 性能 | 三维场景、图表及业务代码产物较大；部分读数查询未分页，大规模历史数据需要分页、聚合与归档 |
| 模型服务 | LLM 依赖网络、服务商权限与额度；模型回复可能出错，操作必须依赖服务端校验与用户确认 |
| 测试与运维 | 部分既有集成测试依赖指定 MySQL 测试库；尚未提供完整 CI、自动备份恢复演练、生产监控与公开 SLA |
| 素材与许可 | 新增原创代码采用 MIT；第三方库、原有图片和外部视频遵循各自授权，详见第三方说明 |

## 后续计划

以下是待实现计划，不代表已上线能力或交付时间承诺。

### P0：可复现运行与基础发布

- 用隔离 MySQL 环境自动验证「空库 → 演示初始化 → 管理员登录 → 页面查询」，覆盖真实 MySQL 方言及重复运行。
- 固化数据库升级版本、前置检查和回滚/恢复步骤，逐步将启动时 schema 修改迁入统一迁移流程。
- 增加后端与前端 CI，明确测试库配置，提供受控的脱敏数据刷新方案。
- 补齐真实页面截图、配置示例和核心告警闭环演示。

### P1：数据与集成质量

- 为真实采集、人工录入、合成样例提供明确且一致的数据来源展示。
- 完善采集器持续数据、网关状态与命令结果回执；用真实新鲜证据验收维修复检。
- 增加读数分页、趋势聚合与历史归档；优化三维场景和图表加载。
- 补充机器可读 OpenAPI、请求示例与接口回归测试。

### P2：生产运维能力

- 按实际部署需求收紧跨域、接入 HTTPS 与访问审计，评估登录限流和细粒度权限。
- 补充服务健康检查、指标监测、日志检索与备份恢复演练。
- 在需要多实例时再引入共享会话协调、分布式锁及任务调度，验证重复写操作和模型确认流程的一致性。
- 根据用户反馈完善助手交互与多机房导航。
