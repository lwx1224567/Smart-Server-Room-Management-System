# 初始化管理员与公开演示数据

工具入口：`cn.guat.tools.ProjectBootstrap`。这是独立命令，不启动 Web 服务，不随正常应用自动执行，也不会读取 `application-local.yml` 中的私密配置。

## 一、新建独立演示库

使用自己的 MySQL 管理账号创建数据库：

```sql
CREATE DATABASE smart_room_demo CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

工具不会创建或删除数据库。`demo` 命令要求 JDBC URL 的库名及实际连接库名均以 `_demo` 结尾，并要求业务表为空；不能拿已有业务库作为演示初始化目标。

## 二、打包工具

在 `后端/smart-park-guat-server/` 下执行：

```bash
mvn -DskipTests package
```

初始化 SQL 一并打进 JAR，工具可以在不启动 Spring 应用的情况下运行。

## 三、配置数据库和管理员凭据

PowerShell 示例，密码交互输入，不放进命令文本或仓库：

```powershell
$env:BOOTSTRAP_DB_URL = 'jdbc:mysql://localhost:3306/smart_room_demo?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia%2FShanghai'
$env:DB_USERNAME = '你的数据库用户名'
$env:DB_PASSWORD = [Net.NetworkCredential]::new('', (Read-Host '数据库密码' -AsSecureString)).Password
$env:BOOTSTRAP_ADMIN_USERNAME = 'demo_admin'
$env:BOOTSTRAP_ADMIN_PASSWORD = [Net.NetworkCredential]::new('', (Read-Host '初始管理员密码（8至128位）' -AsSecureString)).Password
```

Linux / Bash 示例：

```bash
export BOOTSTRAP_DB_URL='jdbc:mysql://localhost:3306/smart_room_demo?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia%2FShanghai'
export DB_USERNAME='你的数据库用户名'
read -r -s -p '数据库密码: ' DB_PASSWORD; echo; export DB_PASSWORD
export BOOTSTRAP_ADMIN_USERNAME='demo_admin'
read -r -s -p '管理员密码: ' BOOTSTRAP_ADMIN_PASSWORD; echo; export BOOTSTRAP_ADMIN_PASSWORD
```

用户名支持 3～100 位字母、数字、下划线、点和短横线。无固定默认密码。

## 四、创建管理员与演示数据

仍在后端目录执行，以下命令适用于 PowerShell 和 Bash：

```bash
java -Dloader.main=cn.guat.tools.ProjectBootstrap -cp target/smartpark-0.0.1-SNAPSHOT.jar org.springframework.boot.loader.PropertiesLauncher admin
java -Dloader.main=cn.guat.tools.ProjectBootstrap -cp target/smartpark-0.0.1-SNAPSHOT.jar org.springframework.boot.loader.PropertiesLauncher demo
```

PowerShell 如果对带点的 `-D` 参数进行特殊解析，可写成 `"-Dloader.main=cn.guat.tools.ProjectBootstrap"`。

- `admin`：必要时创建账号表；创建启用的 `ADMIN`，使用与登录服务相同的 PBKDF2-HMAC-SHA256、120000 次迭代、16 字节随机盐、256 位摘要。
- 同名启用管理员存在时保留密码和资料；同名账号属于其他角色或被禁用时拒绝处理。此工具不是密码重置工具。
- `demo`：初始化 V001 台账结构、V002 合成台账，以及 V004 监测结构；写入 42 个机柜、9 个设备、环境读数、7 天分类能耗、5 个摄像头、4 个空调、拓扑、1 条温度告警与初始化事件。
- 所有监测与能耗来源为 `PUBLIC_DEMO_V1`，记录 JSON 带 `simulated: true`；台账沿用 `MOCK_IMPORT`。当前平台查询使用 `record_origin=REAL`，这是兼容字段，**不意味着这些样例来自真实设备**。
- 不导入真实用户、联系方式、聊天、API Key、旧数据库导出或已处理工单。维保账号请在管理员页面创建，工单通过演示告警转单，避免伪造维修闭环记录。
- 成功后记录版本标记，重复执行直接退出，不刷新时间、不追加样例、不覆盖后来修改的数据。

DDL 在 MySQL 中不能与数据写入整体回滚。若首次建表中断，工具可能留下空表；部分台账表缺失时请在新的空演示库重试，不要对已有业务数据强行补种。工具应在后端停止时单进程运行。

## 五、启动应用与验收

PowerShell 设置后端使用同一个演示库：

```powershell
$env:SPRING_DATASOURCE_URL = $env:BOOTSTRAP_DB_URL
Remove-Item Env:BOOTSTRAP_ADMIN_PASSWORD
java -jar target/smartpark-0.0.1-SNAPSHOT.jar
```

Bash 对应设置 `export SPRING_DATASOURCE_URL="$BOOTSTRAP_DB_URL"`，并执行 `unset BOOTSTRAP_ADMIN_PASSWORD` 后启动 JAR。正常启动时无需设置任何 `BOOTSTRAP_*` 变量。

按根 README 启动前端，使用自行设置的账号密码登录。确认机房/机柜出现、资产页视频可播放、告警列表出现「【演示】机柜温度偏高」、7 天能耗和拓扑有数据。初始样例是静态快照，读数会随时间过期；正式复测需要提交后的新鲜采集证据，不会仅凭初始化样例自动通过。

只需要给已有、已完成台账初始化的数据库创建管理员时，可将 `BOOTSTRAP_DB_URL` 显式指向该库，仅执行 `admin`，不要执行 `demo`。

## 自动验证

```bash
mvn -Dtest=ProjectBootstrapTest test
```

使用 H2 内存库的 MySQL 兼容模式验证初始化、密码编码兼容、重复执行、目标库限制和已有业务拒写，不连接本机开发数据库。这不替代部署环境 MySQL 的首次运行验收。
