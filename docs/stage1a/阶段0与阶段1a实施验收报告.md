# 阶段 0 与阶段 1a 实施验收报告

日期：2026-10-17。范围：仅阶段 0 基线检查，以及阶段 1a 的 A1 会话检查语义、A5 API 错误上下文最小修复。

## 实施结果

- `/auth/me` 返回 HTTP 401：清除本地 token、认证状态，沿用会话失效通知和登录跳转；即使 401 响应为 HTML 而非 JSON，也会清理。
- 超时、断网、HTTP 503、无效 JSON：保留 token，路由进入公开的 `/session-unavailable`；验证成功前不挂载目标受保护页面。该页面显示失败信息与“重新验证”按钮，重试成功后继续原目标地址，并重新应用原角色守卫。
- 403 等非 401 错误也不擅自删除 token，验证未成功时仍阻止进入目标页面。
- 普通 API 错误改为 ApiError，保留 `status`、业务 `code`、`type`、`fields`、`requestId`、`serverTime` 和原有可显示的 `message`。网络与超时分别标记为 `NETWORK_ERROR`、`TIMEOUT_ERROR`，没有 HTTP 响应时 status 为 0。
- 成功响应仍由原 consoleApi 解包，并沿用数据来源归一化；没有另建 HTTP 客户端，没有修改 SSE 协议及客户端。
